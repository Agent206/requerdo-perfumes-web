# Requerdo Perfumes

A modern luxury fragrance storefront for **Requerdo Perfumes**, built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## Features

- **Curated Fragrance Catalog**: Explore signature scents including *Amber Latte*, *Wild Rush*, *Bureau*, *Enigma*, *Twilight*, *Oud Majesté*, and *Aqua Noir* with top, heart, and base note breakdowns.
- **Smooth Page Transitions & Animations**: Custom cursor and fluid transitions powered by Framer Motion.
- **Interactive Cart & Direct Ordering**: Add fragrances to your cart (up to 5 bottles per order) and complete orders seamlessly via WhatsApp.
- **Responsive Design**: Dark editorial aesthetic optimized for both desktop and mobile devices.

## Tech Stack

- **Frontend**: React 19, TypeScript
- **Styling**: Tailwind CSS, Playfair Display & Lato typography
- **Animations & Icons**: Framer Motion, Lucide React
- **Build Tool**: Vite
